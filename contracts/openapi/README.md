# OpenAPI Contracts

Thư mục lưu trữ tài liệu OpenAPI 3.0 / Swagger specs cho từng microservice:

- `identity-service.yaml`: API Specs cho Auth, Users, Roles, Profile.
- `catalog-service.yaml`: API Specs cho Movies, Showtimes, Rooms, Seats, Food, Pricing và Quote API.
- `booking-service.yaml`: API Specs cho Seat Hold, Booking Checkout, Snapshots, QR Check-in.
- `payment-service.yaml`: API Specs cho Payment initiation, VNPay Webhook, Refunds.
- `recommendation-service.yaml`: API Specs cho Movie Recommendation API.
